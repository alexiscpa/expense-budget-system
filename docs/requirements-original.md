# 部門費用預算編列系統

I need you to help me with the following project:

**Goal:**
建立一個企業級各部門費用預算編列系統，採用 React/Next.js + TypeScript + Tailwind CSS 開發。核心功能包含角色權限管理（部門主管與財務管理員）、11 欄位互動填報表單、自動化公式計算與欄位鎖定、雙向加總一致性檢核機制，以及多維度預算彙整與報表匯出功能，實現高效、無紙化的年度預算數位化管理流程。

**Your Role:**
You will act as a 全端工程師.

**What I need you to do:**
1. 設計網站架構與資料模型，規劃權限管理與預算填報的資料庫巢狀結構
2. 實作前端頁面與組件，打造 11 欄位互動填報表單與多維度預算彙整介面
3. 實作後端 API，處理角色權限驗證、預算資料增刪查改與雙向加總一致性檢核邏輯
4. 整合自動化公式計算與欄位鎖定機制，確保部門主管與財務管理員填報時的資料正確性
5. 執行響應式設計與 SEO優化，確保系統在不同載具上的操作體驗與效能
6. 實作多維度預算報表匯出功能，支援 Excel 與 PDF 格式產出
7. 進行全面測試與部署，包含單元測試、整合測試及正式環境上線
